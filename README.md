Descrição:
Nesta atividade, montamos um circuito no Tinkercad usando um Arduino, um botão e um LED. O botão funciona como entrada e o LED como saída. Quando o botão é pressionado, o LED acende, e quando soltamos o botão, ele apaga. Também foi utilizado um código em C++ para programar o funcionamento do circuito.
